Admin Panel — Setup Required

Production admin access will be enabled after server hosting is configured.

Security notice: this page is an implementation checklist, not a live secure admin dashboard. Do not use a browser-only PIN or localStorage to manage real orders, customer data or payments.

What the production admin panel will include

  • Secure admin login with server-side sessions
  • Customer order list and order status management
  • FazerCards supplier order references and webhook status updates
  • Payment verification records and refund/failure handling
  • Product catalog and markup/price controls

The live panel requires hosting, a database and backend API routes. Supplier API credentials must stay on the server and must never be placed in website JavaScript.
